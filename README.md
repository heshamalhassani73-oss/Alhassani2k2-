# Alhassani File Manager (Expo SDK 56)

تطبيق جاهز كقالب لإدارة الملفات وتنظيف الجهاز مبني باستخدام Expo SDK 56.

محتويات المشروع:
- شاشات: استعراض الملفات، تنظيف المساحة، إعدادات.
- دعم لغتين (العربية والإنجليزية) ودعم RTL.
- استخدام expo-file-system وexpo-document-picker مع توضيح قيود أنظمة أندرويد الحديثة.

تعليمات تشغيل سريعة:
1. ثبت Node.js و Yarn أو npm.
2. ثبت Expo CLI: `npm install -g expo-cli` أو استخدم npx.
3. من مجلد المشروع شغل: `npm install` أو `yarn`.
4. شغل التطبيق: `expo start`.

ملاحظة حول الأذونات والقيود:
- بسبب قيود أندرويد الحديثة، لا يمكن للتطبيق الوصول الكامل لملفات تطبيقات أخرى إلا باستخدام Storage Access Framework أو صلاحيات خاصة. هذا القالب يوضح النقاط ويوجه المستخدم لفتح المجلدات المطلوبة.
- لميزات متقدمة (مثل حذف كاش التطبيقات الأخرى)، ستحتاج إلى بناء تطبيق بصلاحيات أوسع أو استخدام EAS وNative modules.
