# وارد 3.0 - نظام إدارة وتتبع المعاملات

نظام متكامل لتتبع وإدارة دورة حياة المعاملات والخطابات الإدارية والحكومية.

## نظرة عامة

**وارد 3.0** هو تطبيق React Native (Expo) مصمم لإدارة المعاملات بدءاً من الاستلام والتسجيل، مروراً بالتوجيه والمتابعة، وحتى الإنجاز والأرشفة النهائية.

## المميزات الرئيسية

### 📊 لوحة التحكم
- عرض إحصائيات فورية عن حالة المعاملات
- رسوم بيانية تفاعلية لتوزيع الحالات والأولويات
- إجراءات سريعة للوصول السريع للوظائف

### 🔄 دورة حياة المعاملة
1. **وصلت** - استلام المعاملة أولياً
2. **قيد التسجيل** - إدخال البيانات والملفات
3. **نشطة** - المعاملة جارية وتحت العمل
4. **موجّهة** - إحالة المعاملة لجهة مختصة
5. **حالات المتابعة** - منتظرة رد / معلّقة / متأخرة
6. **مكتملة** - إنجاز المطلوب بالكامل
7. **مؤرشفة** - نقل المعاملة للأرشيف النهائي

### 🔔 محرك الإشعارات الذكي
- تنبيهات فورية بالمهل الزمنية
- تذكير بالمواعيد النهائية (24 ساعة و ساعتين قبل الانتهاء)
- تنبيهات للمعاملات العاجلة والمتأخرة

### 🔍 البحث والتقارير
- بحث دقيق ومفلتر للوصول السريع
- تقارير إحصائية متعددة الصيغ

### 🔐 الأمان والحماية
- تشفير البيانات الحساسة
- مصادقة عبر رقم PIN أو البصمة (Biometric Auth)
- سلة محذوفات مع إمكانية الاستعادة خلال 30 يوماً

## البنية التقنية

- **الواجهة:** React Native (Expo SDK ~56.0.0)
- **اللغة:** JavaScript/TypeScript
- **قاعدة البيانات:** SQLite (expo-sqlite)
- **المصادقة:** expo-local-authentication
- **الإشعارات:** expo-notifications
- **الرسوم البيانية:** react-native-chart-kit
- **التنقل:** React Navigation 6

## التثبيت والتشغيل

### المتطلبات
- Node.js 18+
- npm أو yarn
- Expo CLI
- محاكي iOS أو Android Device

### خطوات التثبيت

```bash
# تثبيت المكتبات
npm install --legacy-peer-deps

# تشغيل التطبيق
npm start

# للتشغيل على Android
npm run android

# للتشغيل على iOS
npm run ios
```
